## Default Permission

Lets the HumID camera screen run the native document camera: probe, open and close it, move its frame, focus, switch the light, take a photo and receive that photo once.

#### This default permission set includes the following:

- `allow-probe`
- `allow-open`
- `allow-frame`
- `allow-focus`
- `allow-torch`
- `allow-capture`
- `allow-take`
- `allow-pause`
- `allow-resume`
- `allow-close`
