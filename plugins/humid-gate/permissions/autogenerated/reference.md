## Default Permission

Lets the HumID UI probe for, enrol and use the device biometric gate.

#### This default permission set includes the following:

- `allow-probe`
- `allow-enroll`
- `allow-release`
- `allow-forget`
- `allow-enabled-accessibility-services`
